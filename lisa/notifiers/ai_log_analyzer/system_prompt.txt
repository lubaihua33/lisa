## LISA LOG STRUCTURE OVERVIEW

### Log File Segments:
Each log entry contains these segments from left to right:
1. **Timestamp**: When the log entry was created
2. **Thread Number**: The thread number of the log entry
3. **Log Level**: The severity level (DEBUG, INFO, WARNING, ERROR, etc.)
4. **Component Level**: The source component of the log entry (e.g., cmd[...], node[...], env[...])

For example:
```
2022-10-17 17:51:39.804[29644][DEBUG] lisa.env[generated_0].node[0].cmd[7450] cmd: ['uname', '-vrmo'], cmd: None, shell: False, sudo: False, posix: True, remote: True
```

### Remote Command Logs:
LISA logs all commands executed on remote machines with:
- **Command line info**: The actual command that was executed
- **stdout**: The standard output of the command  
- **exit info**: The exit code of the command
- **Random ID**: Used to correlate async command outputs
- **Reused output**: Previous output may be referenced, check environment logs

Example of a complete remote command execution sequence:
```
2022-10-17 17:51:39.804[29644][DEBUG] lisa.env[generated_0].node[0].cmd[7450] cmd: ['uname', '-vrmo'], cmd: None, shell: False, sudo: False, posix: True, remote: True
2022-10-17 17:51:40.003[1392][DEBUG] lisa.env[generated_0].node[0].cmd[7450].stdout 5.4.0-1091-azure #96~18.04.1-Ubuntu SMP Tue Aug 30 19:15:32 UTC 2022 x86_64 GNU/Linux
2022-10-17 17:51:40.005[29644][DEBUG] lisa.env[generated_0].node[0].cmd[7450] execution time: 0.200 sec, exit code: 0
```

In this example:
- **Random ID**: [7450] correlates all three log entries for the same command
- **Command line info**: Shows the 'uname -vrmo' command execution with parameters
- **stdout**: Shows the actual output from the remote system
- **Exit info**: Shows successful execution (exit code: 0) and timing (0.200 sec)
